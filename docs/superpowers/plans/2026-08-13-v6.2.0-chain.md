# js-cool 6.2.0 Chain 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务逐个实现本计划。步骤用 checkbox（`- [ ]`）语法跟踪。

**目标**：发布 js-cool 6.2.0——一个 `chain` 模块（lodash 风格的急求值链式数组操作），复用既有 js-cool 数组函数 + 原生 `Array.prototype` 方法，外加附加镜像 `./chain` 子路径导出。

**架构**：急求值——每个 fluent 方法计算一个新数组并替换内部 `_value`；`.value()` 返回防御性拷贝。单个 `Chain<T>` 类 + `chain<T>()` 工厂；构造函数为 private（仅经 `chain()` 入口）。无 generators / `for...of` / `Symbol.iterator`（IE11 清洁）。

**技术栈**：TypeScript 5.9、Rolldown 1.0-rc、Vitest 3.2（globals + happy-dom）、api-extractor、SWC（IE11 IIFE 的 ES5）、VitePress docs。

**规范**：`docs/superpowers/specs/2026-08-13-v6.2.0-chain-design.md`

## 全局约束

- 基线 6.1.0（假定已发布）。目标 6.2.0（minor）。无破坏性 API 变更。
- 保持 IE11：`src/chain.ts` 中无 generator 函数、无 `for...of`、无 `Symbol.iterator`；spread `[...arr]` 在 SWC 下编译为 `arr.slice()`。
- vitest `globals: true`（裸 `describe`/`it`/`expect`），env `happy-dom`，setup `./test/setup.ts`。直接 import 源码：`from '../src/chain'`。
- Conventional-commit 前缀，祈使语气英文。每任务 TDD：失败测试 → 运行（失败）→ 实现 → 运行（通过）→ 提交。
- 主 `src/index.ts` 仅新增 `chain`/`Chain` 导出；不删除任何内容。

/**
 * Eager chain over js-cool array utilities + native Array methods.
 *
 * @example
 * ```ts
 * chain([{ n: 3 }, { n: 1 }, { n: 2 }])
 *   .filter(x => x.n > 0)
 *   .sortBy('n')
 *   .take(2)
 *   .value()
 * ```
 * @since 6.2.0
 */
export class Chain<T> {
	private constructor(private _value: T[]) {}

	/**
	 * Return a defensive copy of the wrapped array (chain ends).
	 */
	value(): T[] {
		return [...this._value]
	}
}

/**
 * Create a chain wrapping a copy of `value`.
 * @since 6.2.0
 */
export function chain<T>(value: T[]): Chain<T> {
	return new Chain<T>([...value])
}

export default chain
```

- [ ] **步骤 4：向 `src/chain.ts` 的 `Chain<T>` 添加方法**

```ts
	sortBy(...iteratees: SortIteratee<T>[]): Chain<T> {
		return new Chain<T>(sortBy(this._value, ...iteratees))
	}

	unique(by?: keyof T | ((v: T) => unknown)): Chain<T> {
		return new Chain<T>(unique(this._value, by))
	}

	chunk(size: number): Chain<T[]> {
		// chunk returns T[][]; element type narrows from T to T[].
		return new Chain<T[]>(chunk(this._value, size))
	}

	take(n: number): Chain<T> {
		return new Chain<T>(take(this._value, n))
	}

	drop(n: number): Chain<T> {
		return new Chain<T>(drop(this._value, n))
	}

	flatten(): Chain<T> {
		// js-cool flatten is single-level; assumes elements are arrays.
		return new Chain<T>(flatten(this._value as unknown as (T | T[])[]) as unknown as T[])
	}

	sampleSize(n: number): Chain<T> {
		return new Chain<T>(sampleSize(this._value, n))
	}
```

> **类型注：** `chunk` 诚实返回 `Chain<T[]>`（元素变为数组——规范 §5.1 列为 `Chain<T>`，此处更正）。`flatten` 用内部转换，因 js-cool `flatten` 类型为 `(T | T[])[] → T[]`；运行时正确（单层 flatten），类型故意宽松（已记录）。
